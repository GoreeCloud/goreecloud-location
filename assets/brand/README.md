# Official GoreeCloud Location Artwork

This directory is the canonical repository location for the official GoreeCloud Location icon, logo, and related release-controlled artwork.

No placeholder icon is committed during Milestone 0. Once the official visual identity is approved, source artwork and required export sizes should be stored here so application builds, websites, documentation, release packaging, and other GoreeCloud projects can reference the repository rather than relying on scattered copies.

Artwork changes are revision-controlled software-project changes and should preserve source files, licensing/provenance information, and reproducible export guidance where applicable.
